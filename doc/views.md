## Changing Views

If you want to update text, components or logic in one of the views, you must adapt the respective view component. Those can be found in the [frontend/src/app/views/](../frontend/src/app/views/) directory.

| View        | Component                                                           |
|-------------|---------------------------------------------------------------------|
| welcome     | [landing-page](../frontend/src/app/views/landing-page)              |
| end         | [goodbye-page](../frontend/src/app/views/goodbye-page)              |
| survey      | [questionnaire-view](../frontend/src/app/views/questionnaire-view)  |
| tagging     | [tagging-view](../frontend/src/app/views/tagging-view)              |
| saveAndExit | [save-and-exit-page](../frontend/src/app/views/save-and-exit-page)  |
| abort       | [abort-page](../frontend/src/app/views/abort-page)                  |
